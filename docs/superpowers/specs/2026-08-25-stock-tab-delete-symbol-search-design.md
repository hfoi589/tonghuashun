# 股票页签删除与名称联想搜索设计

## 目标

采集页支持从当前浏览器删除单个股票页签，并允许用户通过六位代码或股票名称关键词查找、确认和提交股票。所有候选和确认数据都来自同花顺 App 内部接口，不使用 UI 文本、OCR 或截图。

## 页签删除

- 每个页签由一个 `role="tab"` 的主选择按钮和一个独立删除按钮组成，删除按钮显示在页签右上角，避免嵌套交互元素。
- 点击删除按钮只打开确认弹窗，不切换页签、不触发自动更新。
- 弹窗显示股票名称和代码，并提供“取消”和“删除页签”两个操作；支持 Esc、焦点锁定和关闭后焦点返回原删除按钮。
- 确认后只从当前浏览器的股票页签状态、激活页签状态和 `localStorage` 中移除，不调用服务端删除接口。
- 删除激活页签时，优先激活其右侧页签；没有右侧页签时激活左侧页签。该被动切换不触发自动采集。删除非激活页签时当前内容保持不变。
- “全部股票”选择器继续只负责定位页签，不增加第二套删除入口。

## 名称联想搜索

### App 内部接口

- 在 `FridaParsedValueSource` 增加 `search_symbols(query, limit=8)`，复用现有 `_FRIDA_SYMBOL_LOOKUP_SCRIPT` 和 `queryStockDataList()` App 内部调用。
- 查询文本去除首尾空格，长度限制为 2 至 32 个字符；最多返回 8 条候选。
- 候选必须包含六位代码、非空名称和市场 ID。代码必须属于现有 `market_code_for_symbol()` 支持前缀，返回市场必须与代码预期市场一致。
- 按 `(symbol, market)` 去重并保留 App 返回顺序；过滤债券市场、未知市场、空名称、错误市场和重复项。
- App/Frida 不可用或超时保留原始接口错误码，不使用 UI 或 OCR 降级。

### 公共 API

- 新增 `GET /api/v1/symbols?query=<关键词>&limit=8`，返回 `SymbolLookupResponse[]`。
- `query` 长度 2 至 32；`limit` 范围 1 至 8，默认 8。参数错误返回 `422`。
- 无候选时返回 `200 []`；App 内部查询失败返回 `503`。
- 保留 `GET /api/v1/symbols/{symbol}` 作为六位代码唯一精确确认接口。
- 模糊搜索结果不写入已确认股票缓存。用户选择候选后，前端必须再调用精确确认接口；精确确认成功后才沿用现有缓存和任务提交逻辑。

## 前端交互

- 采集输入框允许中文、字母和数字，文案改为“输入股票代码或名称”。
- 输入内容是六位数字时，取消模糊请求并执行现有精确查询。
- 其他输入达到 2 个字符时，延迟 300ms 发起候选请求；每次输入变化中止上一请求，避免过期结果覆盖新结果。
- 下拉候选显示“名称、六位代码、市场标签”，最多 8 条；支持鼠标、触摸、上下方向键、Enter 选择和 Esc 关闭。
- 选择候选后，将输入框替换为六位代码并调用精确确认接口。确认期间提交按钮禁用；确认成功后展示现有绿色股票确认区并允许提交。
- 用户重新编辑输入框时清除已选择和已确认状态。点击输入框外部关闭候选列表。
- 状态分别显示：正在搜索、没有匹配股票、候选查询暂不可用、正在精确确认、精确确认失败。
- 选中并提交后继续复用现有唯一任务和页签逻辑：已有股票页签被激活、更新并置顶；新股票加入当前浏览器页签。

## 错误与并发处理

- 模糊搜索失败不阻止用户改用六位代码查询。
- 请求序号和 `AbortController` 双重防止乱序响应。
- 输入法组合输入期间不发请求，`compositionend` 后再开始查询。
- 删除页签时取消该页签对应的前端重试等待状态；服务端正在进行的采集任务不取消，其他浏览器不受影响。

## 测试与验收

- Frida 解析测试覆盖名称关键词、市场过滤、债券过滤、去重、数量限制、空结果和原始错误码。
- API 测试覆盖候选成功、空结果、参数校验、503，以及候选不能绕过精确确认。
- 前端测试覆盖 300ms 防抖、旧请求取消、键盘选择、选择后精确确认、无结果和失败状态、最终提交六位代码。
- 页签测试覆盖删除确认/取消、删除激活和非激活页签、相邻页签选择、仅修改当前浏览器存储，以及删除按钮不触发页签更新。
- 完整运行 Python 测试、Vitest、TypeScript/Vite 构建，并在桌面和移动宽度检查下拉框、确认弹窗和页签布局。

## 部署

- 使用 OrbStack 和现有双环境文件执行标准 Compose 重建。
- 部署后用关键词“国盾”验证候选返回“国盾量子（688027）”，再选择并精确确认代码，最后提交任务验证页签自动加入。
- 验证删除页签只影响测试浏览器，Redis 唯一任务数量不因删除而减少。
