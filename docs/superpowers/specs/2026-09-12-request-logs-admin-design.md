# 查询日志 Admin 页面设计

## 目标

在 Admin 页面提供查询日志，记录查询者 IP、设备类型、浏览器标识、股票代码/名称及任务结果。

## 约束

复用现有 SQLite；默认保留 90 天；仅记录查询与任务相关请求；仅 Admin 可查看；不记录 Token、Cookie、协议帧、完整请求体或敏感认证信息；股票名称只采用本地证券目录确认结果。

## 方案

FastAPI 请求中间件采集固定字段并写入独立 request_logs 表。Admin 提供分页、时间/股票/状态/IP 筛选接口，React AdminPage 增加日志页签、刷新和空/错状态。后台定期清理过期记录。
