# 核心 9528 直连隔离分析记录（2026-08-27）

本记录只保存脱敏的结构结论，不保存 Cookie、User-Agent、认证包、请求包、
协议密钥或原始行情响应。原始测试帧仅存在于本机临时目录，未写入仓库。

## 静态证据

- 设备内热更新 DEX 的 `com.hexin.middleware.data.mobile.StuffCurveStruct`、
  `defpackage.upv`、`defpackage.cjv` 和 `defpackage.gov` 已反编译核对。
- `StuffCurveStruct` 的曲线数据解析链为：`cv3.*` 头 → 点数/首点/字段数 →
  字段 ID 与类型 → 小端 short/int/HXLONG → `dataTable`；扩展字段进入
  `extDataTable`。
- HXLONG 的缺失哨兵包括 `-2147483648`、`-1`、`0x80000000`、`0xffffffff`；
  缩放由符号位、十进制位数和除/乘方向决定。
- `miv.c()` 在 `qiv` 结构解析之前调用 native `miv.e(byte[], cjv)`，随后才做
  Snappy/Zstd 处理。当前实际 SHSL 响应的高位加密标志为空，低位压缩标志为
  `0x1000`，因此所需变换是标准 Snappy raw 解压，不进入对称密钥分支。

  当前 MACDFS 参数 `[10,20,5]`，材料只保留在加密会话存储约定内。
- 在新 TCP 连接上只发送认证包，服务端返回了合法的 13 字节外层帧头及完整
  认证响应。
- 等待认证响应后只发送一个请求模板，服务端继续返回控制帧和 `cv3.0.` 业务
